## Как пересобрать

Отчёты собираются из исходников [`src/`](src) и актуальных документов репозитория, поэтому
после правки `Docs/*.md` или `README.md` достаточно пересобрать:

```powershell
pip install python-docx pillow
python Docs/Reports/build_reports.py        # все отчёты; или: ... build_reports.py 3 5
```

PDF — через Microsoft Word: содержимое [`export_pdf.ps1`](export_pdf.ps1) (или «Файл →
Сохранить как → PDF» в Word). Скриншоты для отчётов лежат в [`images/`](images).
