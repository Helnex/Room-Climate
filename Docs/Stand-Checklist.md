## 2. Сеть: телефон ↔ сервер

Для каждого расклада: открыть в браузере телефона `http://<IP компьютера>:8000/health`,
затем открыть приложение и дождаться «Сервер найден».

| № | Расклад | Ожидаемый результат | Итог |
|---|---|---|---|
| 2.1 | Телефон и компьютер в одной Wi‑Fi | `/health` → `{"status":"ok"…}`, приложение находит сервер само | |
| 2.2 | Телефон раздаёт интернет, компьютер подключён к нему | То же; IP компьютера смотреть в `network-check.ps1` | |
| 2.3 | Компьютер раздаёт интернет (мобильный хот-спот Windows) | То же | |
| 2.4 | 2.1 + VPN на компьютере (FlClash) | `network-check.ps1`: «Локальная сеть … идёт мимо VPN»; приложение работает | |
| 2.5 | 2.1 + VPN на телефоне | Работает, либо понятное сообщение «на телефоне включён VPN…» | |
| 2.6 | USB: `scripts\usb-connect.ps1`, Wi‑Fi на телефоне выключен | Приложение находит сервер на `127.0.0.1:8000` | |
| 2.7 | Подключение по QR: отсканировать QR со страницы `/connect`, нажать «Открыть в приложении» | Тост «Сервер подключён: https://…:8443»; дальше всё работает по HTTPS | |
