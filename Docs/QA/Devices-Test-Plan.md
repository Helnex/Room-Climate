# Чек-лист тестирования: «Устройства» (платы и датчики из базы сервера)

Ручная проверка экранов «Устройства», «Новое помещение», «Добавление датчика»,
«Выбор датчика», «Выбор помещения» на реальном телефоне. Телефон подключается к ноутбуку
по USB (отладка по USB), действия выполняются через `adb`.

## Подготовка

- Сервер (стенд) доступен: `http://<стенд>:8000/health` → `{"status":"ok"}`. Телефон в той же Wi-Fi сети.
- APK собран из проверяемой ветки: `adb install -r app-debug.apk` (пакет `com.example.roomclimate`).
- Генератор данных для плат без железа:
  `python roomclimate/collector/fake_boards.py http://<стенд>:8000 pi-2:18 pi-3:25 --extra light`
  (`INGEST_TOKEN` — из окружения или `server/.env`, в отчёт не попадает).
- Аккаунты только тестовые: `qa-<время>@example.com`. Для помещений брать **Платы № 0002 и № 0003**,
  Плату № 0001 (настоящая Raspberry Pi) не занимать.

Полезные команды:

| Что | Команда |
|---|---|
| Снимок экрана | `adb exec-out screencap -p > shot.png` |
| Элементы экрана | `adb shell uiautomator dump /sdcard/ui.xml && adb exec-out cat /sdcard/ui.xml` |
| Нажатие / ввод | `adb shell input tap X Y`, `adb shell input text "..."` (латиница) |
| Следующее поле / назад | `adb shell input keyevent 61` / `keyevent 4` |
| Падения | `adb logcat -c` до теста, `adb logcat -d -b crash` после |
| Wi-Fi | `adb shell svc wifi disable` / `enable` |
| Тёмная тема | `adb shell cmd uimode night yes` / `no` |

## Проверки

| № | Проверка | Ожидается |
|---|---|---|
| 1 | Новый аккаунт без помещений | «Устройства»: «0 помещений · 0 плат · 0 датчиков», карточки «Помещений пока нет» и «Датчики не подключены». Дашборд: «Добавить помещение в «Устройствах» ›», никаких чужих показаний |
| 2 | Новое помещение | Список «ПЛАТЫ ИЗ БАЗЫ СЕРВЕРА · N»; плата сама не выбрана; занятые серые и не выбираются; пустое название и повтор названия — понятные ошибки |
| 3 | Помещения в «Устройствах» | «Sklad1 · Плата № 0002», сводка пересчиталась, у помещения кнопка «+» |
| 4 | Добавление датчика | Датчик из базы сервера; «Выбор датчика»: счётчики «ВСЕ / СВОБОДНЫ», занятые серые; показатель берётся из записи датчика и не меняется; второй датчик того же вида на одну плату — понятная ошибка |
| 5 | Показания | С генератором: «На связи · 16,6 °C · 51 % · Плата № 0002»; значения обновляются сами (≈15 с); без генератора через 3–4 мин — «Не на связи · последние: …» |
| 6 | Дашборд | Подписано, какое помещение показано; первое помещение с датчиком температуры само попадает на дашборд, следующие — нет; переключение через «Показывать на дашборде» |
| 7 | Действия с датчиком | Переименовать; «Вынести на дашборд» / «Убрать с дашборда»; «Отвязать от платы» — датчик снова свободен, его карточка исчезает с дашборда |
| 8 | Действия с помещением | Состояние платы (заголовок «Плата № …»), выгрузка CSV за неделю, переименовать, удалить |
| 9 | Поворот экрана | В «Добавлении датчика» выбранные датчик и помещение сохраняются |
| 10 | Навигация | «Назад» на всех экранах; переход на вкладку из экранов выбора не возвращает на них по «Назад» |
| 11 | Смена аккаунта | Второй аккаунт не видит помещений, карточек и показаний первого; его платы — «Занята» |
| 12 | Оформление | Диалоги скруглённые, кнопки зелёные без капслока (светлая и тёмная тема); «Плата № 0002» и «49 %» не разрываются при переносе |
| 13 | Без сети | Режим полёта: понятное сообщение, без падения (только с разрешения владельца телефона) |

## Уборка после теста

Отвязать датчики, удалить помещения, удалить тестовые аккаунты («Аккаунт» → удалить аккаунт),
остановить генератор. Платы № 0002/0003 и датчики № 0142–0147 снова «Свободна» / «Свободен».
