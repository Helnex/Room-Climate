# RoomClimate — система мониторинга климата в помещении

Учебный командный проект по дисциплине «Технология командной разработки программ»
(ПНИПУ, кафедра ИТАС, группа РИС-23-2б, 7 семестр).

- **Репозиторий:** https://github.com/Helnex/Room-Climate
- **Доска задач (канбан):** https://github.com/users/shmim385/projects/2

## Описание проекта

RoomClimate — система для наблюдения за температурой, влажностью и другими показателями
воздуха в помещении. Датчики подключаются к плате Raspberry Pi, плата каждые 10 секунд
отправляет показания на сервер, сервер хранит историю и проверяет пороги, а Android-приложение
показывает текущие значения, графики за выбранный период и присылает уведомление, когда
показатель вышел за заданный пользователем диапазон.

Предметная область — контроль микроклимата: жилые помещения (квартира, дом, гараж),
офисы, серверные, склады и небольшие производственные участки, где важны
температурно-влажностные условия.

## Назначение проекта

Продукт создаётся для людей, которые отвечают за климат в одном или нескольких
помещениях, но не могут постоянно находиться рядом с термометром: владельцев квартир и
домов, сотрудников складов и офисов. Сейчас показания доступны только на самом приборе,
а о выходе температуры за допустимые пределы узнают слишком поздно (испорченный товар,
плесень, перегрев серверной). RoomClimate даёт:

- текущие показания каждого помещения на телефоне — не нужно подходить к датчику;
- историю и графики — видно, как менялся климат за сутки, неделю, месяц;
- уведомление о выходе за свой порог для каждого помещения — экран можно не держать открытым.

Система только наблюдает и предупреждает: она не управляет отоплением, вентиляцией и
увлажнителями.

## Быстрый старт

Сервер (нужен Docker Desktop):

```powershell
cd roomclimate/server
docker compose -p roomclimate up -d --build
python smoke_test.py
```

Документация API работающего сервера — http://127.0.0.1:8000/docs, имитация платы —
`python simulate_collector.py`. Подробнее — в [`roomclimate/README.md`](roomclimate/README.md)
и README каждого модуля.

## Правила работы с репозиторием

Изменения — только в короткой ветке под задачу с доски и через pull request в `main`;
каждый PR проверяют GitHub Actions и хотя бы один участник команды. Подробно — в
[`Docs/ci-cd.md`](Docs/ci-cd.md).
