# RoomClimate - система мониторинга климата в помещении
Мобильное приложение для мониторинга температуры и влажности в помещении в реальном времени с получением уведомлений при выходе показателей за допустимые границы. Приложение предусмотрено для сотрудников складов, цехов и производственных участков, где критичны температурно-влажностные условия, а также для владельцев квартир, домов и офисов, желающих контролировать климат в помещении.
# Задачи
   Подключение датчика температуры и влажности, датчика освещенности к Raspberry Pi, чтение данных через GPIO, отправка телеметрии на сервер.
   Разработка backend на Linux: REST API, хранение истории измерений.
   Android-приложение: дашборд с текущими показателями, графики за сутки.
# Функциональные требования
  - Система должна считывать температуру и влажность с датчика
  - Система должна сохранять каждое измерение в базу данных
  - Система должна предоставлять текущие показатели по запросу от мобильного приложения
  - Система должна предоставлять историю измерений за выбранный период.
  - Система должна принимать новые пороговые значения от мобильного приложения.
  - Приложение должно отображать текущую температуру и влажность в помещении.
  - Приложение должно строить график температуры и влажности за указанный период.
  - Приложение должно отправлять уведомление при температуре выше или ниже установленного критического значения.
# Нефункциональные требования
  - Система должна обеспечивать время отклика API не более 3 секунд.
  - Система должна работать на Raspberry Pi OS (64-bit) с Python 3.11+.
  - Приложение должно быть разработано на языке Java с использованием актуальной версии Android SDK и Android Studio.
  - Система должна непрерывно работать.
  - Система должна работать в локальной сети Wi-Fi без доступа в интернет.
  - Приложение должно работать на Android 8.0 и выше.
  - Приложение должно иметь интерфейс на русском языке.
